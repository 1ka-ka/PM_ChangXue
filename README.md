## 已实现功能（MVP）

### 账号与个人中心

- 手机号 + 密码注册（开户赠 50 积分）、JWT 登录（7 天有效期）、退出登录
- 资料编辑（昵称/学校/简介）、头像上传（格式校验 + 自动压缩）
- 个人主页：我的提问（按状态筛选）、我的收藏（帖子/回答）、积分明细流水
- 他人主页只读浏览；主题装扮接口已预留（P2 启用，当前返回默认值）

### 提问与互动

- 发帖提问：标题/正文/1-3 个学科标签/悬赏档位（10/20/50/100 积分，同事务扣分）
- 帖子配图：最多 9 张，格式 magic bytes 校验 + 压缩至 1280px
- 发帖草稿本地缓存（localStorage），意外关闭可恢复
- 15 分钟编辑窗口；软删除（悬赏不退回）
- 回答：每用户每帖 1 条可编辑；禁止自问自答；已采纳回答锁定不可改删
- 双层评论（帖子/回答均可评论，二楼封顶）
- 点赞（帖子/回答/评论）、收藏（帖子/回答）

### 采纳与知识库

- 提问者采纳回答（每帖上限 3 个）：单事务完成 置已解决 + 收录知识库 + 奖励回答者 30 积分 + 感谢值三周期累加 + 站内通知
- 最佳答案标记（仅可标记已采纳回答，切换零账务）
- 采纳后问答自动进入知识库，搜索优先命中

### 广场与搜索

- 广场三 Tab：最新 / 待解决 / 推荐（热度 + 悬赏加权 + 14 天衰减）
- 待解决帖超 7 天无回答标注"已 X 天未有回答"
- 搜索：知识库优先 → 未命中自动降级广场全文检索（记录降级埋点）→ 双空态引导提问
- 支持标签筛选；防 SQL 注入转义

### 相似问答推荐（v1.1.0）

- 发帖页防重复：输入标题防抖 600ms 实时提示"已有相似问题"，点击直达历史帖
- 帖子详情页底部"相关问题"推荐（排除自身，最多 5 条）
- 冷启动算法：标题字符 bigram Jaccard 相似度 + 标签重合加权（0.15/个，上限 0.3）+ 已解决加成 0.1 + 回答数加成；阈值 0.2 过滤无意义结果
- 软删帖自动排除；量大后可切 MySQL 全文索引或 LLM 相似推荐（网关契约已留）

### AI 功能（v1.2.0 起接入，v1.3.0 五场景全部上线，配置驱动）

- **LLM 网关客户端**（`backend/app/gateway/client.py`）：五场景统一调用入口（summary / ref_answer / reliability / quality / moderation），阿里云百炼 DashScope OpenAI 兼容接口（qwen-turbo / qwen-plus 按场景路由）；默认超时 10s（ref_answer 场景放宽 60s）、失败重试 2 次、任何失败抛降级异常由调用方静默处理，绝不拖垮主流程；模型输出 JSON 严格按契约校验（`contracts.py`）
- **AI 摘要（summary，v1.2.0）**：发帖/编辑后异步生成 ≤100 字摘要（BackgroundTasks，独立会话）；详情页展示"AI 摘要"块（标注"由 AI 自动生成，仅供参考"）；列表卡片优先显示 AI 摘要并带 AI 徽标；LLM 不可用时自动降级回正文截断，无感知
- **AI 参考回答（ref_answer，v1.3.0）**：详情页"暂无回答"时用户可触发生成（同步约 10-30s），结果缓存于 `post.ai_answer` 一次性生成；标注"由 AI 生成，仅供参考，不可被采纳"
- **回答可靠性评分（reliability，v1.3.0）**：回答提交/编辑后异步生成 0-100 评分与"高/中/存疑"等级，回答列表展示徽标（Tooltip 注明"仅供参考，不代表官方认定"）
- **回答质量检测（quality，v1.3.0）**：提交回答时实时检测低质灌水（结合作者历史回答），命中拦截 40913 不入库；LLM 故障时静默放行，AI 故障不停摆社区
- **举报违规分级（moderation，v1.3.0）**：举报提交后异步生成"极高/高/低"分级与违规类型，管理后台举报队列展示 AI 标签辅助分诊（不代表最终认定）
- Key 通过 `backend/.env` 配置（已 gitignore，严禁提交）；`LLM_ENABLED=false` 时全部场景静默降级；测试环境恒关、零真实调用

### 消息与激励

- 五类站内通知：被回答/被评论/被回复/被采纳/被点赞（自互动不通知）
- 通知中心：未读角标（99+）、全部已读、点击直达帖子；被删内容通知自动标记失效
- 积分体系：开户 50 / 每日登录 5 / 被采纳 30 / 发帖悬赏支出；日封顶 100；流水余额连续可审计
- 助人榜：周榜/月榜（感谢值结算，APScheduler 周一/月初自动结算，前三领奖台样式）

### 治理与管理后台

- 举报：五类理由 + 补充说明（敏感词过滤、同目标去重）
- 管理后台（仅管理员）：数据看板（待处理举报/DAU/日发帖/日采纳）
- 举报处置四动作：删除内容（级联软删帖→回答→评论+通知失效）/ 封禁作者（1 天/7 天/永久）/ 追回积分（钳制至余额 0）/ 驳回
- 标签管理（新增/改名/排序/停用）、操作日志全留痕

### 基础设施

- 统一响应信封 `{code, msg, data}` + 五段错误码（40001 参数 / 40102 未登录 / 40301/40302 权限 / 40901-40911 业务冲突 / 50001 内部）
- 埋点批量上报（sendBeacon 兼容，限流 60 次/分/IP）
- LLM 网关五场景契约（摘要/参考答案/可信度/质量检测/内容审核，P0 零调用仅占位）
- 敏感词 DFA 过滤器；软删除全链路一致性

## 本地一键运行（开发模式，热更新）

### 前置条件（仅首次）

1. Python 3.12+，在 `backend/` 下建虚拟环境并装依赖：

   ```powershell
   cd backend
   python -m venv .venv
   .venv\Scripts\pip install fastapi uvicorn sqlalchemy alembic pydantic-settings python-jose passlib bcrypt pillow python-multipart apscheduler httpx pytest
   ```

2. Node.js 20+，在 `frontend/` 下装依赖：

   ```powershell
   cd frontend
   npm ci --legacy-peer-deps
   ```

### 启动

**AI 功能（可选）**：在 `backend/` 下创建 `.env`（已被 gitignore 忽略，不会提交）配置 LLM：

```ini
LLM_ENABLED=true
LLM_API_KEY=你的Key
LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
```

未配置时 AI 功能全部静默降级（摘要回退正文截断），其余功能不受影响。

**双击项目根目录的 `dev.bat`**，脚本会自动：

1. 自检前后端依赖是否就绪（缺依赖会给出补装命令）
2. 启动后端 `http://127.0.0.1:8000`（uvicorn `--reload`，代码改动自动重启；dev 环境自动建 SQLite 库 + seed 12 个学科标签）
3. 启动前端 `http://localhost:5173`（Vite 热更新，`/api` 与 `/uploads` 自动反代到后端）
4. 自动打开浏览器

**停止**：关闭弹出的「畅学-后端8000」「畅学-前端5173」两个窗口即可。

### 体验管理员后台

MVP 无注册管理员的入口，本地体验时把任意用户提为管理员（开发库 `changxue.db`）：

```powershell
cd backend
.venv\Scripts\python -c "from app.core.database import SessionLocal; from app.models import User; from sqlalchemy import update; db=SessionLocal(); db.execute(update(User).where(User.nickname=='你的昵称').values(role=1)); db.commit(); print('ok')"
```

重新登录后头像菜单出现「管理后台」入口。

## 生产部署与使用

### 部署（服务器，Linux + MySQL + Nginx）

`deploy/` 目录提供三件套，服务器上执行：

```bash
bash deploy/deploy.sh
```

脚本自动完成：装 Nginx → 后端 venv + 依赖 → 生成 `.env`（**需手动改数据库口令与 JWT 密钥后重跑**）→ MySQL 建库 + Alembic 迁移 + seed 标签 → 前端构建 → systemd + Nginx 注册并启动。

配置文件说明：

| 文件                          | 作用                                              |
| --------------------------- | ----------------------------------------------- |
| `deploy/nginx.conf`         | 前端静态 + history 路由回退 + `/api` 反代 + `/uploads` 直出 |
| `deploy/changxue.service`   | systemd 托管 Uvicorn（2 worker，崩溃自动拉起）             |
| `deploy/deploy.sh`          | 一键部署/更新脚本                                        |

### 上线后如何使用

| 角色   | 使用方式                                                                    |
| ---- | ----------------------------------------------------------------------- |
| 普通用户 | 浏览器访问站点 → 注册（手机号+密码，赠 50 积分）→ 搜索/逛广场 → 提问（可选悬赏）→ 回答别人问题赚积分 |
| 回答者  | 回答被采纳得 30 积分 + 感谢值，周/月榜上榜                                              |
| 提问者  | 对满意回答点「采纳」（≤3 个），可再标「最佳」；首个采纳后帖子置为已解决并自动入知识库            |
| 举报   | 帖子/回答右上角「举报」，选理由提交                                                      |
| 管理员  | 登录后头像菜单 →「管理后台」：看板 / 举报处置（删除·封号·追分·驳回）/ 标签管理 / 操作日志        |

运维要点：

- 升级：`git pull && bash deploy/deploy.sh`（Alembic 增量迁移，seed 幂等）
- 日志：`journalctl -u changxue -f`
- 数据备份：MySQL `changxue` 库 + `backend/uploads/` 目录
- 首任管理员：MySQL 直接 `UPDATE user SET role=1 WHERE phone='...'`（MVP 无后台任命入口）

## 项目结构

```
├── dev.bat                  # 一键开发启动（本 README 配套）
├── deploy/                  # 生产部署三件套（nginx/systemd/deploy.sh）
├── backend/
│   ├── app/
│   │   ├── core/            # 配置/数据库/响应信封/错误码/JWT/敏感词
│   │   ├── models/          # 20 表 SQLAlchemy 模型
│   │   ├── modules/         # 12 业务模块（account/credit/post/accept/feed/search/notify/rank/moderation/admin/tracking/gateway）
│   │   ├── gateway/         # LLM 五场景契约（P0 占位）
│   │   └── jobs/            # 榜单定时结算
│   ├── migrations/          # Alembic 迁移
│   ├── scripts/             # seed 标签 / smoke_e2e.py 端到端回归
│   └── tests/               # pytest 99 用例

│   ├── stores/              # Pinia（登录态/未读数）
│   └── api/                 # Axios 封装 + OpenAPI 生成类型
└── PROJECT_STATE.md         # 开发状态追踪（阶段/决策/坑点，开发协作者必读）
```
